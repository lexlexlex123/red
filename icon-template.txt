СТРУКТУРА
════════════════════════════════════════

ICONS — полный список без дублей.
  id, alias, name, p (части через ||), mixed?, olymp?

ICON_CATS — категории, icons:[id,…]
Умолчания UI: прозр. заливки 0.3, толщина 1.4.
Холст: viewBox 0 0 24 24.

════════════════════════════════════════
ДВА ПРЕФИКСА (+ простой режим)
════════════════════════════════════════

  s:   только контур (линия), без заливки
  f:   только заливка, без обводки

Круг — обычный path (дуги), как у лупы:
  M11 19a8 8 0 100-16 8 8 0 000 16z

Три способа рисовать значок:

  1) ПРОСТОЙ — без f:/s: во всём p
     Весь SVG: заливка + контур от UI (как Search id:40).
     p:'M11 19a8 8 0 100-16 8 8 0 000 16z||M21 21l-4.35-4.35'

  2) MIXED — части с f: или s:
     Каждая часть отдельно: f: = заливка, s: или без префикса = контур.

  3) Заливка + контур одной фигуры — две части с одним path:
     f:M12 2a10…z||s:M12 2a10…z

Дырки во f: (evenodd) — автоматически, если в path несколько M.

Лупа (простой, заливка+контур от UI):
  {id:'40', alias:'search', name:'Search',
   p:'M11 19a8 8 0 100-16 8 8 0 000 16z||M21 21l-4.35-4.35'}

Круг залит + галочка контуром:

   p:'f:M12 4A8 8 0 0012 20Z||s:M12 4a8 8 0 100 16 8 8 0 000-16z', mixed:true}
