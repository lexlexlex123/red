Offline EN↔RU translation models for «Слайды»

Engine: Bergamot / Marian NMT (Mozilla Firefox Translations), MPL-2.0
WASM: @browsermt/bergamot-translator 0.4.9

Layout:
  enru/  — English → Russian (tiny)
  ruen/  — Russian → English

Files are uncompressed and shipped with the app so translation works
without downloading models at runtime. Open the editor via HTTP
(run.bat / localhost) so the Web Worker can load the WASM module.
