**Автор:** Некрасов Александр

## Быстрый старт

Распакуйте архив и откройте `index.html` в браузере. Интернет не требуется (кроме отдельных функций вроде онлайн-AI).

Для PWA, CORS и SharedArrayBuffer удобнее HTTP-сервер:

```
run.bat          # python -m http.server и открытие браузера
```

После установки как приложения (PWA) оболочка кэшируется офлайн; `.html` / `.json` можно открывать через «Открыть с помощью».

```
slides_project/
├── index.html
├── manifest.webmanifest    — PWA, File Handling (.html/.htm/.json)
├── sw.js                   — Service Worker / precache
├── css/styles.css          — все стили UI (см. раздел «Интерфейс»)
├── config/                 — настройки переходов, тем и т.д.
├── icons/                  — иконка приложения (icon.svg / PNG)
└── js/
    ├── 00-i18n.js          — локализация, APP_VERSION
    ├── 00-pwa.js           — установка PWA, launchQueue
    ├── 07-transitions.js   — переходы между слайдами

    ├── 24-preview.js       — показ, морфинг
    ├── 26-export.js        — экспорт / импорт HTML и PPTX
    ├── 26b-ppt-binary.js   — импорт classic .ppt (OLE)
```

## Возможности

### Элементы
| Тип | Описание |
|-----|----------|
| **Текст** | Форматированный, 6 стилей границы |
| **Изображение** | PNG/JPG/SVG, crop, flip, rx, opacity |
| **Фигура** | 30+ фигур, скругление Bezier, тень без обрезки |
| **Кривая** | Редактор узлов, корректный drag и Shift-мультивыделение |
| **Таблица** | Редактируемые ячейки |
| **Формула** | LaTeX (MathJax); голосом — формулы и молекулярные структуры |
| **Код** | Подсветка, тема dark/light, полупрозрачный фон |
| **Иконка** | 1000+ иконок |
| **Аудио / Видео** | Встроенные медиа с триггерами |
| **Аплеты** | Калькулятор, часы, таймер, заметки, QR — имена RU/EN |
| **LEGO** | Кирпичики, скосы |

### Переходы, показ и экспорт
- **Морфинг** — плавное перемещение объектов между слайдами (без мигания)
- **Анимация «Цвет»** — силуэт при показе с плавным проявлением цвета; цвет/инверсия/задержка/длительность
- Flip / FlipV с корректной скоростью и офлайн-экспортом
- **F5** — показ с первого слайда; **Shift+F5** — с текущего (как в PowerPoint)
- В режиме показа объекты не выделяются и не редактируются
- **Экспорт HTML** — автономный файл для показа; без синего выделения при клике
- **Импорт HTML** — round-trip: экспортированный `.html` снова открывается в редакторе (формат `_sl`)
- **Импорт PPTX** — PowerPoint 2007+ (ZIP/OOXML)
- **Импорт .ppt** — классический binary PowerPoint 97–2003 (OLE), позиции фигур и текст без autoplace

### PWA
- Установка как приложение, офлайн-кэш оболочки
- **File Handling** — ассоциация с `.html` / `.htm` / `.json` через `launchQueue`
- Иконка ленты и приложения — `icons/icon.svg`

### Буфер обмена
- **Ctrl+C / Ctrl+V** — объекты и слайды
- **Между вкладками** — копирование в одной вкладке, вставка в другой (`localStorage`)
- Вставка слайда через **Ctrl+V** — в конец презентации
- Контекстное меню слайдов — вставка в место клика

### Слайды
- Имена по умолчанию: **«Презентация»**, **«Слайд N»** (RU/EN через i18n)
- Мультивыделение: Ctrl/Shift + клик по миниатюре
- Контекстное меню: добавить, дублировать, копировать, вставить, удалить
- Вставка между слайдами по позиции Y

### Голосовое управление 🎙
200+ команд на русском: показ, слайды, объекты, формулы/структуры, перемещение с числами и словами («двадцать пикселей»), нечёткое распознавание и журнал нераспознанных команд (📋).

### Группировка
`Ctrl+G` / `Ctrl+Shift+G` — группировать / разгруппировать.

## Интерфейс: кнопки и переключатели

При добавлении нового UI **не изобретайте стили с нуля** — используйте существующие классы из `css/styles.css` и CSS-переменные. Так новые панели будут выглядеть как часть приложения.

### CSS-переменные (тема)

| Переменная | Назначение |
|------------|------------|
| `--accent` / `--accent-h` | Основной синий, hover |
| `--accentl` | Светлый фон активного состояния |
| `--accent2` | Розовый (предупреждение, удаление) |
| `--surface`, `--surface2`, `--surface3` | Фоны панелей и hover |
| `--border`, `--border2` | Границы |
| `--text`, `--text2`, `--text3` | Основной / вторичный / приглушённый текст |

Светлая тема: класс `html.light` переопределяет те же переменные.

### Кнопки ленты (ribbon) — `.rb`

Вертикальная кнопка: иконка SVG сверху, подпись `.rbl` снизу.

```html
<button class="rb" onclick="…">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.8">…</svg>
  <span class="rbl">Подпись</span>
</button>
```

| Модификатор | Когда использовать |
|-------------|-------------------|
| *(без)* | Обычное действие |
| `.rb.on` | Режим включён (toggle-кнопка ленты) |
| `.rb.pri` | Главное действие (синий фон) |
| `.rb.warn` | Опасное / особое (розовый текст) |

Размер иконки: **15×15 px**, stroke **1.8**, подпись **9 px**.

Логотип в шапке — `<img src="icons/icon.svg">`, не инлайн-SVG.

### Кнопки модальных окон — `.mbtn`

```html
<button class="mbtn">Отмена</button>
<button class="mbtn pri">Применить</button>
<button class="mbtn dan">Удалить</button>
```

Горизонтальные, padding `6px 16px`, font-size **11 px**.

### Компактные кнопки панели свойств — `.tbtn2`

Для сеток переходов, мелких опций в `#props`:

```html
<button class="tbtn2">Fade</button>
<button class="tbtn2 active">Morph</button>
```

Активное состояние — класс **`active`** (не `on`).

### Кнопки выравнивания / зума — `.albtn`

Квадрат **25×25 px**, только иконка:

```html
<button class="albtn" title="…"><svg …></svg></button>
<button class="albtn active">…</button>
```

Иконка **12×12 px**.

### Кнопки форматирования текста — `.ftbtn`

Bold, align, фон слайда и т.п.:

```html
<button class="ftbtn" onmousedown="event.preventDefault()"><b>B</b></button>
<button class="ftbtn on">…</button>
```

Размер **26×24 px**. Toggle — класс **`on`**.

### Сегментированный переключатель — `.ar-group` + `.ar-btn`

Два и более взаимоисключающих варианта (например, соотношение сторон):

```html
<div class="ar-group">
  <button class="ar-btn active">16:9</button>
  <button class="ar-btn">4:3</button>
</div>
```

Активная кнопка — **`active`**, синий фон `#fff` текст.

### Переключатель темы (сегмент) — `.theme-toggle` + `.theme-btn`

Как в настройках dark/light:

```html
<div class="theme-toggle">
  <button class="theme-btn active">Тёмная</button>
  <button class="theme-btn">Светлая</button>
</div>
```

### Toggle (вкл/выкл) — `.tog`

**Единственный правильный паттерн** для boolean-опций (тень, snap, градиент, ∞ для анимаций):

```html
<label class="tog">
  <input type="checkbox" id="my-opt" onchange="…">
  <span class="tog-track"></span>
  <span class="tog-thumb"></span>
</label>
```

- Размер: **36×20 px**, бегунок **14×14 px**
- Выключен: трек `#2a2f3a`, включен: `--accent`
- Подпись рядом — отдельный `<span>` или `<label>`, font-size **11 px**, `color: var(--text2)`
- Для Snap: обёртка `.sntog` (toggle + текст)

**Не используйте** нативный `accent-color` checkbox или самодельные div-toggle — только `.tog`.

### Вкладки ленты — `.rtab`

```html
<button class="rtab active">Главная</button>
```

Подчёркивание снизу цветом `--accent`.

### Контекстное меню — `.slide-ctx-item`

```html
<button type="button" class="slide-ctx-item">
  <span class="slide-ctx-ico"><svg …></svg></span>
  <span class="slide-ctx-lbl">Копировать</span>
</button>
<button class="slide-ctx-item disabled">…</button>
<button class="slide-ctx-item slide-ctx-warn">Удалить</button>
```

### Иконки в UI

- Ribbon / контекстное меню: **stroke**, `currentColor`, viewBox `0 0 24 24`
- Не смешивайте fill-иконки и stroke-иконки в одной панели без причины
- Размеры: ribbon 15 px, albtn 12 px, ctx-menu 14 px

### Общие правила

1. **Шрифт:** `font-family: inherit` на всех кнопках  
2. **Transition:** `.1s`–`.12s` на hover/active  
3. **Активное состояние:** `.active` или `.on` — фон `var(--accentl)`, border `var(--accent)`, текст `var(--accent)`  
4. **Primary action:** `.pri` — сплошной `--accent`  
5. **Disabled:** `opacity: .38`, `pointer-events: none` (см. `.slide-ctx-item.disabled`)  
6. **user-select: none** на кнопках уже задан глобально  
7. Новые блоки в `#props` — обёртка `.fmt-block`, заголовки как у соседних секций  
8. Не хардкодить цвета `#3b82f6` — только `var(--accent)`

## История версий

### v6.4 (2026-08-08)
- **Анимация «Цвет»** — выделение: силуэт по контуру (изображение/текст), цвет и инверсия в настройках
- При показе объект сразу в силуэте; после задержки плавно проявляется исходный цвет (длительность = переход)
- Экспорт HTML и предпросмотр поддерживают ту же логику

### v6.3 (2026-08-05)
- **Импорт .ppt** — binary PowerPoint 97–2003 (OLE): фигуры, текст, изображения, гиперссылки; размер слайда как в файле
- **PWA File Handling** — открытие `.html` / `.htm` / `.json` через установленное приложение (`launchQueue`)
- **F5 / Shift+F5** — показ с начала / с текущего слайда
- **Голос** — формулы и молекулярные структуры, устойчивое перемещение, нечёткое распознавание, журнал нераспознанных команд

### v6.2 (2026-06-20)
- **Показ (F5)** — объекты не выделяются синим, drag/resize заблокированы; при выходе не появляются дубликаты (снимок слайда, защита `save()`)

- **Импорт HTML** — исправлен round-trip: чтение данных из `<script id="_sl">` (экспортированные презентации снова импортируются)

- **Переходы flip** — скорость по умолчанию «Нормально», офлайн-экспорт
